# Интерактивный анализ QSL в Zed

[English](EDITOR_EN.md)

В версии 0.5 информация распределена между обычными инструментами редактора.

| Где | Что показано |
|---|---|
| После закрывающей скобки схемы | Размер кадра или динамический диапазон |
| Рядом с именем поля | Размер кодирования и известное смещение, включая биты |
| Hover поля | Rust-тип, размеры и смещения, опциональность, тег, работа с памятью |
| Hover схемы | Краткая таблица кадра, метаданных, RT и валидации |
| CodeLens / действия кода | Раскладка, события длины, сгенерированный Rust |
| Дерево документа | Схемы, поля и константы DEQ |
| Автодополнение | Типы, атрибуты схем, значения атрибутов и модификаторы строк |
| Переход к определению | Локальные схемы, загруженные константы DEQ, найденные Rust-шаблоны |
| Диагностика | Синтаксис, диапазоны, повторные объявления, порядок полей, несовместимые режимы |

Действие просмотра раскладки открывает Markdown-документ в кеше анализа Zed. В нём находятся полная таблица полей на проводе и состояния графа длин. Исходная схема не изменяется. Просмотр Rust открывает настоящий результат генератора и требует соответствующего native-анализатора.

Доступны явный перенос фиксированных обязательных полей перед переменными и переключение RU/EN для текущего сеанса. Изменение порядка меняет wire-format и выполняется только по выбранному действию. Перезапись, которая потеряла бы комментарии между полями, не предлагается.

## Включение подсказок

Zed по умолчанию отключает inlay hints и CodeLens. Добавьте следующие значения в `.zed/settings.json` проекта или настройки пользователя, сохранив существующие параметры. `language`: `ru`, `en` или `auto`. Auto использует язык клиента, а при его отсутствии — системную локаль. Для постоянного выбора используйте настройки; действие кода меняет язык только текущего сеанса сервера.

```json
{
  "code_lens": "on",
  "languages": {
    "QSL": { "inlay_hints": { "enabled": true } },
    "DEQ": { "inlay_hints": { "enabled": true } }
  },
  "lsp": {
    "qsl-lsp": {
      "initialization_options": {
        "language": "ru",
        "inlayHints": { "enabled": true, "schemas": true, "fields": true, "offsets": true },
        "codeLens": true
      }
    }
  }
}
```

`inlayHints.schemas`, `fields`, `offsets` и `codeLens` включаются независимо. После изменения initialization_options перезапустите сервер языка. Поддержано также событие `workspace/didChangeConfiguration`. Справка Zed: [настройки LSP](https://zed.dev/docs/configuring-languages), [inlay hints и CodeLens](https://zed.dev/docs/reference/all-settings).

## Точный native-анализ

Из соответствующего проекта QSL:

```powershell
cargo build --manifest-path qsl/Cargo.toml --bin qsl-analyze --features rust-macros --release --locked
```

Сервер ищет бинарный файл в проекте и родительских каталогах текущего документа, включая `qsl/target/release/` и `target/release/`. Явный путь задаётся через `initialization_options.analyzerPath` или `QSL_ANALYZER`. Несовместимый анализатор отклоняется с предупреждением; предварительные оценки помечаются. Сбои запуска, неверный JSON и внутренние ошибки сервера больше не скрываются.

Изменения DEQ и Rust-шаблонов обновляют анализ; учитываются несохранённые значения DEQ. Поиск Rust-файлов ограничен и служит подсказкам: список входов сборки по-прежнему задаёт build.rs. Диагностика синтаксиса и диапазонов сохраняется при успешном native-разборе. Некорректная схема не получает достоверных подсказок раскладки. Неизвестные смещения пропускаются в подсказках рядом с кодом, а не повторяются у каждого поля.

Размер wire-кадра отличается от `size_of::<T>()`. Rust может переставлять поля и добавлять padding; точный размер нативного объекта определяет rustc. Анализатор не подставляет выдуманное число и не объявляет неизвестный custom-кодек неограниченным. Если границы compact/custom-поля не установлены, отображается динамическое или неизвестное значение. Степень сжатия не предсказывается по одному Q.

Пример: [inspect.qsl](../zed-qsl/examples/inspect.qsl). В графе отдельно показаны гарантированные и возможные поля, резерв метаданных и payload. Упаковка Q2–Q16 сохраняет точность. Команды редактора не запускают бенчмарки.

## Проверка

```powershell
node --test zed-qsl/server/test.js zed-qsl/server/editor.test.js
tree-sitter test
cargo build --manifest-path zed-qsl/Cargo.toml --target wasm32-wasip2 --release --locked
```

Проверяются оба языка, появление и исправление ошибок, inlay hints, hover полей, дерево документа, completion, определения, настройки, изменения UTF-16 и открытие раскладки и Rust-кода. Проверки native явно пропускаются, если рядом нет собранного анализатора.

В текущей раскладке клавиатуры Zed меню действий открывается через `Ctrl+.`.

## QPS и предсказание

`[qps]` включает точное сжатие числовым операндом; квант по умолчанию — Q16. Поддержаны явные Q2/Q4/Q8/Q16 и синоним `quant=Qn`. Опциональные поля для QPS не требуются. Предсказание состояний по длине независимо выполняет `opt_table`. Старый формат D/индексов явно обозначается `state_bits`. Обе стороны должны согласовать кодек и квант. Точный native-анализ требует ревизию кодека 2; при старом анализаторе оценки помечаются как предварительные.

Для ссылки на Rust-макрос подсказка показывает число раскрытых полей. Hover содержит все развёрнутые поля, их размеры и смещения; размер первого поля не выдаётся за размер всей группы.
